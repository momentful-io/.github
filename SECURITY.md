# Security Policy

This policy applies to all projects in the [momentful-io](https://github.com/momentful-io) GitHub organization, unless a repository provides its own `SECURITY.md`.

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public issues, discussions, or pull requests.

Instead, report them privately using the **"Report a vulnerability"** button in the **Security** tab of the affected repository ([how it works](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)). If you are unable to use GitHub, please get in touch via the contact details on [momentful.io/imprint](https://momentful.io/imprint/) and we will arrange a private channel. Please do not include any vulnerability details in that first message.

Please include as much of the following as you can:

- the affected project and version (or commit)
- a description of the vulnerability and its potential impact
- steps to reproduce or a proof of concept

## What to Expect

Momentful I/O is a community-driven open-source initiative, and reports are handled on a best-effort basis. We will look into your report as soon as we can and keep you informed about our progress. Once the issue is resolved, we will publish a security advisory and credit you for the discovery, unless you prefer to remain anonymous.

Please give us a reasonable amount of time to fix the issue before disclosing it publicly.

## Reports Created with AI Tools

If you used AI tools to find or write up an issue, please say so and make sure you have verified the issue yourself. Reports that cannot be reproduced or do not demonstrate a real impact may be closed without further response.

## Supported Versions

Unless a project states otherwise, security fixes are provided for the latest release only.
