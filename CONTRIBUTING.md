# Contributing to Momentful I/O

Thank you for your interest in contributing! Momentful I/O is an open-source initiative, and contributions of all kinds are welcome: code, documentation, translations, design, bug reports, and ideas.

These guidelines apply to all repositories in the [momentful-io](https://github.com/momentful-io) GitHub organization. Individual projects may provide their own `CONTRIBUTING.md` with project-specific details such as build setup, coding style, or tests. If they do, those take precedence.

## Code of Conduct

Everyone participating in Momentful I/O is expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting Bugs and Suggesting Features

- Search the existing issues first to avoid duplicates.
- Open an issue in the affected repository. For bugs, describe the steps to reproduce as well as the expected and actual behavior.
- **Security vulnerabilities must not be reported in public issues.** Please follow our [Security Policy](SECURITY.md) instead.

## Contributing Changes

1. For anything beyond small fixes, please open an issue first so we can agree on the approach before you invest your time.
2. Fork the repository and create a branch from `main`.
3. Keep pull requests focused on a single change and explain what you changed and why.
4. Make sure existing tests pass and add tests where it makes sense.
5. Be patient: maintainers review contributions as time allows.

## Use of AI Tools

You may use AI tools to help with your contribution, but you remain responsible for it:

- Review, understand, and test everything you submit, and be ready to explain it during review.
- Mention in your issue or pull request if a substantial part of it was generated with AI tools.
- Make sure the generated content does not infringe any third-party licenses or copyrights.

Contributions that appear to be unreviewed AI output may be closed without further discussion.
